# OfficeTools

A modern, responsive office tools access management system built using React, Vite, TailwindCSS, Firebase, and Supabase. This project is designed to handle access to office tool equipment and system information efficiently.

## 🚀 Features

- ⚡ Fast development powered by **Vite**
- 🧩 Modern component structure with **React**
- 🎨 Clean and extendable UI using **TailwindCSS**
- 💫 Smooth animations via **Framer Motion**
- 🔐 Authentication and database support with **Firebase** and **Supabase**
- 📊 Charts and analytics using **Recharts**
- 🔔 Toast notifications using **react-hot-toast**
- 🎛️ Reusable components with **Radix UI**

## 🛠️ Setup & Development

### 1. Clone the Repository

```bash
git clone https://github.com/Hyelkali/office-tool.git
cd office-tool
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the root directory and add:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_SUPABASE_URL=https://your-supabase-url.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 4. Run Development Server

```bash
npm run dev
```
